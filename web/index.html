引擎约定

  • 无未来函数：策略在第 t 根 K 线收盘产生信号，成交发生在第 t+1 根开盘价。
  • 向量化引擎：单 bar 收益 = opent+1/opent − 1，成本 = 换手率 ×（佣金+滑点）。毫秒级，适合几千组参数扫描。
  • 事件驱动引擎：逐 bar 推进，含真实股数、手续费、盘中止损/止盈/移动止损、A股 T+1。用于最终验证。
  • 行业惯例：先用向量化扫参数，再用事件驱动精验证。
  • 口径差异：向量化按持仓段计交易（一段连续持仓 = 1 笔），事件驱动按实际成交计。 因此连续型策略（vol_target / grid）在两引擎下交易次数会差很多，但净值应基本一致。

成本模型（为什么默认参数会骗你）

  • A 股：卖出印花税 0.05% + 佣金万 2.5（最低 5 元）+ 过户费 0.001%。
  • 港股：印花税 0.10% 双边 + 交易征费/交收费/交易费合计约 0.014% + 佣金 0.05%。往返成本约 0.53%。
  • 美股：多数券商零佣，成本主要是买卖价差与冲击成本。
  • 滑点可用成交量冲击模型：冲击 ∝（委托量 / 当日成交量）²，小资金近乎无滑点，大资金显著变差。
  • 含义：策略的每笔预期毛利必须高于往返成本，否则交易越勤亏得越快。

稳健性验证（四项，彼此独立、可交叉验证）

  • 自助置信区间：平稳块自助（Politis-Romano），保留波动率聚集，给出夏普/收益/回撤的 5%–95% 区间。
  • 随机策略对照（Aronson）：保持交易次数与持仓时长不变，把入场时机随机重排 N 次。真实策略落在随机分布的第几百分位 → p 值。 它回答的是「赚的钱来自择时还是来自 beta」，与「是否显著为正」是两个不同问题。
  • 通缩夏普比（Bailey & López de Prado）：扫了 N 组参数后，最好的夏普本来就会偏高。DSR 把这个选择偏差扣掉。
  • 参数高原：把最优参数微调一档，看表现是否断崖式下跌。断崖 = 过拟合孤岛。

组合回测

  • 支持截面动量轮动（每期按过去 N 日涨幅排序买最强的 top_k）与全标的持有。
  • 加权：等权 / 波动率倒数 / 风险平价（迭代使各标的风险贡献相等，单标的上限 60% 防角点解）。
  • 再平衡日之间权重随价格漂移，只在再平衡日付成本 —— 不这么做会低估换手成本。
  • 输出年换手率、各标的贡献、相关性矩阵（平均两两相关高 = 分散是假象）。

样本外检验（Walk-Forward）

  • 把区间切成 N 折，每折前 70% 做训练（网格寻优选最佳参数），后 30% 做测试。
  • 只把各折测试段的净值拼接起来 —— 这条曲线从未参与过任何参数选择，是“诚实”的绩效。
  • 若样本外夏普远低于样本内，说明参数过拟合。

指标口径

  • 夏普 / 索提诺 / 波动率按数据频率自动年化（日线 252，加密货币 7×24 按 365）。
  • Calmar = 年化收益 / |最大回撤|。
  • 盈亏比 = 总盈利 / 总亏损；胜率 = 盈利单占比。
