引擎约定

  • 无未来函数：策略在第 t 根 K 线收盘产生信号，成交发生在第 t+1 根开盘价。
  • 向量化引擎：单 bar 收益 = opent+1/opent − 1，成本 = 换手率 ×（佣金+滑点）。毫秒级，适合几千组参数扫描。
  • 事件驱动引擎：逐 bar 推进，含真实股数、手续费、盘中止损/止盈/移动止损、A股 T+1。用于最终验证。
  • 行业惯例：先用向量化扫参数，再用事件驱动精验证。

样本外检验（Walk-Forward）

  • 把区间切成 N 折，每折前 70% 做训练（网格寻优选最佳参数），后 30% 做测试。
  • 只把各折测试段的净值拼接起来 —— 这条曲线从未参与过任何参数选择，是“诚实”的绩效。
  • 若样本外夏普远低于样本内，说明参数过拟合。

指标口径

  • 夏普 / 索提诺 / 波动率按数据频率自动年化（日线 252，加密货币 7×24 按 365）。
  • Calmar = 年化收益 / |最大回撤|。
  • 盈亏比 = 总盈利 / 总亏损；胜率 = 盈利单占比。
