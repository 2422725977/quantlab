# QuantLab

向量化 + 事件驱动混合的量化回测工作台。Web 界面操作，支持参数扫描、样本外检验、**稳健性验证**与**多标的组合回测**。

```
python run.py serve     # → http://127.0.0.1:8765
```

## 设计取舍

参考了 backtrader / vectorbt / zipline / qlib / backtesting.py / bt / freqtrade / LEAN 的取舍，
按「研究阶段快、验证阶段准」的工业惯例把两种范式合在一起：

| 引擎 | 用途 | 特点 |
|---|---|---|
| **向量化** | 参数扫描、想法快速验证 | NumPy 全程向量化，上千组组合秒级完成；单 bar 收益 = open<sub>t+1</sub>/open<sub>t</sub> − 1 |
| **事件驱动** | 最终验证 | 逐 bar 推进，真实股数/成本模型，**盘中止损·止盈·移动止损**、A股 T+1 |

两个引擎共用同一套策略信号，实测净值差异 < 1%，互为交叉校验。

## 快速开始

```bash
pip install -r requirements.txt

```

## 无未来函数

策略在第 t 根 K 线**收盘**产生信号 → 引擎顺延到第 t+1 根**开盘价**成交。两条引擎都严格遵循这一约定。

## 四个工作台页签

### 1. 单策略回测 + 诊断

绩效卡片、净值/回撤双轴、价格叠加仓位、月度收益、成交明细，外加**诊断层**：

- **逐笔分析**：SQN（Van Tharp 策略质量分）、MAE/MFE（最大不利/有利偏移）、盈亏比、最大连亏、持仓时长、暴露时间、按出场原因分组
- **滚动夏普 / 滚动回撤**：绩效是否只来自某一段时间
- **年度 × 月度热力图**、分年收益 vs 基准
- **收益分布**：VaR95 / CVaR、尾部比、Omega、偏度峰度、稳定性 R²、最长回撤持续天数

### 2. 参数扫描

网格全组合，按夏普 / CAGR / Calmar / 索提诺 / 盈亏比等排序，附指标分布直方图（判断是否存在"只有个别参数好"）。

### 3. 样本外检验（Walk-Forward）

切成 N 折，每折前 70% 训练、**后 30% 测试**，只把各折测试段净值拼接。判据：样本外夏普明显低于全区间 = 过拟合。

### 4. 稳健性验证（四项，彼此独立、互相交叉验证）

| 检验 | 回答的问题 | 参考 |
|---|---|---|
| **自助置信区间** | 结果可复现吗？给出夏普/收益/回撤的 5%–95% 区间 | Politis-Romano 平稳块自助（保留波动率聚集） |
| **随机策略对照** | 赚的钱来自**择时**还是**beta**？ | Aronson《Evidence-Based Technical Analysis》 |
| **通缩夏普比** | 扣掉"扫了多少组参数"后还显著吗？ | Bailey & López de Prado (2012/2014) |
| **参数高原** | 最优点是高原还是孤岛？ | 邻域扰动稳定性 |

**关键**：后两项问的是**不同问题**，结论可以不一致。例如"夏普显著为正（DSR 通过）但只是跟着标的涨（随机对照 p=0.16 不通过）"——这说明择时没有增量信息，只是吃到了 beta。界面会把这个差异显式标出来。

随机对照的做法：保持**交易次数与持仓时长分布不变**，只把入场时机随机重排 N 次，看真实策略落在随机分布的第几百分位。

### 5. 组合回测（多标的）

- **截面动量轮动**（每期按过去 N 日涨幅排序买最强的 top_k，可跳过最近几日避开短期反转）或全标的持有
- 加权：等权 / 波动率倒数 / **风险平价**（不动点迭代使各标的风险贡献相等，单标的上限 60% 防角点解）
- **再平衡日之间权重随价格自然漂移**，只在再平衡日付成本——不这么做会显著低估换手成本
- 输出年换手率、各标的收益贡献、相关性矩阵（平均两两相关高 = 分散是假象）
- 同一信号下三种加权方式的横向对比

## 真实成本模型

很多回测"看起来能赚"，实盘一上就被成本吃掉。内置按市场的费率：

| 市场 | 往返成本 | 构成 |
|---|---|---|
| **A 股** | 0.302% | 佣金万 2.5（**最低 5 元**）+ 卖出印花税 0.05% + 过户费 0.001% |
| **港股** | 0.529% | **印花税 0.10% 双边** + 交易征费/交收费/交易费 + 佣金 0.05% |
| **美股** | 0.100% | 零佣，成本主要是价差与冲击 |
| **加密货币** | 0.200% | taker 0.05% |

滑点支持三种模型：固定比例、**成交量冲击**（冲击 ∝ (委托量/成交量)²，zipline VolumeShareSlippage 思路）、固定价差。

## 数据源

| 市场 | 主源 | 降级源 | 备注 |
|---|---|---|---|
| A 股 | AkShare（前复权） | — | 需 `pip install akshare` |
| 港股 | 腾讯财经（前复权） | yfinance | **分段回溯可突破 1000 根上限**（实测拿到 2015 年以来 2900+ 根） |
| 美股 | 腾讯 `usfqkline`（`.OQ`/`.N` 后缀） | yfinance | 实测 AAPL 可拿到 2200+ 根 |
| 加密货币 | ccxt / Binance | 换 `--exchange okx` | 国内访问 Binance 可能需要代理 |

腾讯接口单次返回上限 1000 根，因此 `data.py` 实现了**分段回溯**：固定 end 逐段往前取，直到覆盖 start 或触到上市首日。

行情缓存在 `quantlab/.cache/`（CSV，默认 1 天过期）。

## 已知边界

- 向量化引擎不模拟盘中止损（属事件驱动引擎职责）。
- 交易次数口径：向量化按**持仓段**计（一段连续持仓 = 1 笔），事件驱动按**实际成交**计，连续型策略两者会差很多，但净值应一致。
- 向量化不模拟涨跌停、流动性约束；事件驱动按开盘价全额成交，未做成交量上限。
- Walk-Forward 折内训练样本不足（< 40 根）会跳过该折。
- 风险平价在标的数量少（< 3）且波动率差异大时会退化为近似等权（上限约束生效）。
- 加密货币与部分美股数据源依赖外网，国内环境可能需代理。
